# 架构说明

## 目标

做一款 **Android 离线背棋谱** App：浏览内置棋谱、逐步复盘、背谱练习、本地记录进度。无账号、无后端。

## 分层

```
┌─────────────────────────────────────┐
│  UI（Expo Router 页面）               │
│  列表 / 复盘 / 背谱练习               │
├─────────────────────────────────────┤
│  practice 状态机（待实现）            │
│  当前步、等待走子、对错、提示         │
├─────────────────────────────────────┤
│  board + engine（待实现）             │
│  棋盘渲染 + xiangqi.js 合法着校验     │
├─────────────────────────────────────┤
│  manuals（内置 JSON）                 │
│  progress（AsyncStorage）             │
└─────────────────────────────────────┘
```

## 目录约定

| 路径 | 职责 |
|------|------|
| `src/app/` | 路由页面；不要放业务组件 |
| `src/components/` | 可复用 UI（棋盘、着法列表等） |
| `src/data/manuals/` | 内置棋谱；新增一局 = 加一个 JSON + 在 index 注册 |
| `src/lib/` | 进度读写、着法转换等 |
| `src/types/` | 共享类型 |
| `docs/` | 设计文档 |

## 关键交互

1. **复盘**：前后步进，展示当前局面与着法注释。
2. **背谱**：轮到 `sideToMemorize` 时由用户走子；与谱着 `uci` 比对；错误则提示并重试该步；正确则自动走出对手着（若只背一方）。
3. **进度**：`progress:{manualId}` 存 `maxReached`、各步错误次数。

## 不做什么（当前阶段）

- 在线对弈、云同步、账号体系
- AI 分析 / 引擎算杀
- 完整 XQF 图形编辑器
- 复杂变例树编辑（第二期再考虑分支）

## 包名

Android / iOS 包名已定为 `com.xiang.xiangqimanual`（见 `app.json`）。上架后勿轻易修改。
