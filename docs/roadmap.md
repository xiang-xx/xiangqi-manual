# 路线图

## MVP（当前目标）

- [x] Expo + TypeScript + Expo Router 脚手架
- [x] 棋谱 JSON 规范与示例谱（tags + 注释）
- [x] 首页：最近背谱 + tag 筛选 + 列表
- [x] 进度读写（AsyncStorage）
- [x] 木纹棋盘 + 圆形汉字棋子
- [x] 接入 `xiangqi.js` 走子与合法着
- [x] 背谱模式：双方由人走，校验谱着
- [x] 记谱模式：上一步 / 下一步自动走子
- [x] 着法说明展示、提示 / 重来
- [x] PGN/ICCS 导入脚本骨架
- [x] 棋盘翻转（背黑方）
- [x] 解残棋：只走解题方、对方 AI 弱档应着（无引擎回退主变）、将杀判定、本地进度
- [x] AI 对弈：Pikafish 离线引擎 + 难度档位（Android 开发构建）
